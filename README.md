# Riemann Remark: Bilingual Reading Companion

An independent English–Russian reading companion to Levent Alpöge’s reported manuscript on the Riemann hypothesis and the Dirichlet generalized Riemann hypothesis. This project does not verify or endorse the reported proof.

[Original public PDF](https://alpo.ge/remark.pdf)

Licensing and verification notes will follow. The original PDF and its linked archives are not redistributed here.
